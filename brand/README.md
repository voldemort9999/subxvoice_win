# SUBXVoice brand files

Everything here is generated by `apps/desktop/scripts/build-brand.mjs` from the same definition
the app draws (`apps/desktop/src/shared/mark.ts`). Don't edit these files by hand; change the mark
there and run:

```bash
node apps/desktop/scripts/build-brand.mjs
```

## The two marks

**The logo: the X of SUBX.** A straight cream line (the text) crossed by an ultramarine wave (the
voice): speaking turns into writing, inside the X of the name. Used for the app icon, the Dock,
the menu bar, the website and anything that names the product.

**The motion: a wave and a blinking underscore.** The voice still moving and the cursor waiting
for the words. Used wherever SUBXVoice is working: the pill while it writes, the launch screen,
loading states. It is the logo's movement, never a replacement for the logo.

## Colours

| | Hex | Used for |
|---|---|---|
| Soft black | `#161412` | the plate behind the mark, and the ground it sits on |
| Butter cream | `#f2e8c8` | the line; the wordmark |
| Ultramarine | `#6b7cff` | the wave, always |

Type in the wordmark: Funnel Display, 800 for SUB, 400 for Voice (embedded in the SVGs).

## Which file for what

| Need | File |
|---|---|
| App icon on macOS | `app-icon/SUBXVoice.icns` |
| App store, social avatar, large icon | `app-icon/icon-1024.png`, `png/subx-icon-*.png` (16–1024) |
| Website favicon | `app-icon/favicon.ico` (16, 32, 48) |
| The mark on a dark background | `svg/subx-mark.svg`, `png/subx-mark-*.png` |
| Name and mark together, dark background | `svg/subx-wordmark-on-dark.svg`, `png/subx-wordmark-on-dark-*.png` |
| The motion, moving (web, slides) | `svg/subx-motion.svg` (on the plate), `svg/subx-motion-transparent.svg` |
| The motion, still | `svg/subx-motion-static.svg`, `png/subx-motion-*.png` |

PNG sizes are in the file name: the icon and mark by pixel width, the wordmark by pixel height.
SVGs scale to any size and are the files to give a designer or a printer.

## Don't

- Don't change the colours of the line and the wave, or swap them: cream is the text, blue is
  the voice.
- **The logo is always the black-theme one**: the soft-black plate with the cream line and the
  blue wave. There is no white or light version, and none should be made. On a light page, use
  the icon with its plate (`png/subx-icon-*.png`), never the bare mark.
- Don't stretch, rotate or outline it.
